inCTRL - Windows Shortcut Commands Quiz & Platform

Kör projektet:
1. Starta databasen med Docker:
   docker compose up -d

2. Starta Backend:
   cd backend
   npm install
   npm run dev    (eller npm start)

3. Starta Frontend (i separat terminal):
   cd frontend
   npm install
   npm run dev

Databas:
- MySQL körs i Docker på port 3306.
- Databasnamn: inctrl_db
- Initieras automatiskt via docker/init.sql med schema och data för kortkommandon, quizfrågor, användare och poäng.

Felsökning i Windows PowerShell:
Om du får felet "running scripts is disabled on this system" när du kör `npm`:
- Kör antingen kommandot en gång i PowerShell:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
- Eller kör med `.cmd`: `npm.cmd install` och `npm.cmd run dev` (eller `node app.js`)

Tester och testtäckning (Coverage):
- Backend (>99% coverage):
    cd backend
    npm test
- Frontend (100% coverage):
    cd frontend
    npm test
