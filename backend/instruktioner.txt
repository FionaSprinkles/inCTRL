inCTRL - Backend & MySQL via Docker

1. Starta MySQL via Docker Compose (i rotmappen):
   docker compose up -d

   Detta startar MySQL 8.0-containern ('inctrl-mysql') och kör automatiskt 'docker/init.sql'
   som skapar databasen 'inctrl_db' med tabeller för quizfrågor, användare, kategorier,
   kortkommandon och resultat.

2. Installera beroenden för backend:
   cd backend
   npm install

3. Starta backend-servern:
   npm start
   (eller npm run dev för live-reload med node --watch)

4. API-ändpunkter:
   - Health check:     GET  http://localhost:3000/api/health
   - Quizfrågor:       GET  http://localhost:3000/api/questions
   - Kortkommandon:    GET  http://localhost:3000/api/shortcuts
   - Användare:        GET  http://localhost:3000/api/users
   - Kategorier:       GET  http://localhost:3000/api/categories
   - Topplista:        GET  http://localhost:3000/api/quiz/leaderboard
   - Skicka svar/resultat: POST http://localhost:3000/api/quiz/attempts
     (Body: { "answers": { "sc-1": "opt-1", ... }, "formatFilter": "all", "timeSpentSeconds": 30 })

5. Felsökning i Windows PowerShell:
   Om du får felet "running scripts is disabled on this system" när du kör `npm`:
   - Tillåt skript för ditt användarkonto i PowerShell:
       Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   - Eller kör med `.cmd`:
       npm.cmd install
       npm.cmd run dev (eller node app.js)
